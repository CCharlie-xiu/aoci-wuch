## Reporting a vulnerability

Please do **not** open a public Issue for security reports.

Email **1453346832@qq.com** or **chouxiucheng@gmail.com**, or report privately via GitHub Security Advisories:

https://github.com/CCharlie-xiu/aoci-wuch/security/advisories/new

Include impact, reproduction steps, and whether a public exploit exists if known. We will confirm and reply with a handling plan as soon as we can.

## Scope notes

- This repository is a documentation / skill library. Treat any credentials that appear in examples as placeholders—never commit real secrets.
- PRO / subscription content is delivered outside the public tree; do not attempt to bypass [auth](https://skill.wuch-ai.net/auth.html) or redistribute subscription codes.
- The project site at [skill.wuch-ai.net](https://skill.wuch-ai.net/) is static GitHub Pages; report site or auth-page issues through the same private channels.
