# gap-protocol.md · 覆盖不到时主动查

本能力没写到的，先查官方，再答。禁止凭记忆补菜单路径或参数。

## 触发

| 情形 | 判定 |
| --- | --- |
| `index.md` 路由表无命中 | 缺口 |
| 命中文件里没有对应小节 | 缺口 |
| 要给的控制台路径在 `index.md` 页面分工里无 `✓` | 未核实，先查 |
| 用户追问超出文件细节（GTM 界面、受众、BigQuery 等） | 缺口 |
| 链接打不开或页面显示不存在 | 记为失效，换页再查 |

## 流程

```text
1 判定缺口
2 在 index.md 页面分工 A 找最接近的官方页 → 抓取
3 A 表没有 → 限定官方域名检索（见下）→ 抓取
4 抓取失败 → 重试一次 → 换同主题其他页 → 仍失败进入 6
5 回答并标注来源（见格式）
6 全部失败：声明「未核实」，不补路径，给用户自查入口
7 用户确认有用 → 沉淀（见下）
```

## 检索规则

| 项 | 规则 |
| --- | --- |
| 域名 | 检索限定 `support.google.com`、`developers.google.com`。不限域名会返回博客转载，易过期 |
| 优先级 | 官方帮助页 > 官方开发者页 > 其他。其他来源须标注「非官方」，不得单独作依据 |
| 关键词 | 中英各试一次；菜单名以英文官方页为准，再对应中文界面 |
| 链接检测 | 本机 `curl` 访问 Google 域名可能全部返回 000，改用页面抓取判断是否存在 |
| 页面失效 | 抓到「页面不存在」→ 从 `index.md` 删除，并换为有效页 |

## 回答格式

每个现查结论带三项：

```text
来源：<URL>
核对日期：<YYYY-MM-DD>
性质：能力库 / 现查官方 / 未核实
```

- 菜单路径来自官方英文页时，注明「中文界面名称以实际显示为准」。
- 官方页没写的细节（如某按钮在哪），写「官方未说明」，不推测。

## 搜不到

```text
我没有在官方文档里核实到这一项。
请在 Analytics 右上角帮助 / support.google.com/analytics 搜索「<关键词>」，
或把你看到的界面截图发我，我据此指路。
```

## 沉淀

用户确认结论有用后：

1. 路径或链接 → 补进 `index.md` 页面分工，并标 `✓` 与核对日期。
2. 操作步骤 → 补进对应文件（`analysis.md`、`user-analysis.md`、`code-map.md`）。
3. 改动走 `follow/update.md`，提交前运行 `python3 scripts/validate.py`。
