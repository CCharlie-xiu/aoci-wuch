# 询问清单

执行本能力时，**在写 Canvas 之前**用自然语言向用户收集下列信息。可合并成一轮问答；缺项再补问。

## 必问

1. **用途**  
   只要「当前基线总览」，还是「针对某产品 / 某页面的风格板」？

2. **产品一句话**（若不是纯总览）  
   例如：「安静的画布，正在生长的界面。」

3. **要展示哪些板块**（多选）  
   - 双表面与工作台骨架  
   - 色板（冷中性 / 松绿 / 状态 / 品牌蓝 / 图表）  
   - 字体三声部样张  
   - 间距 · 圆角 · 高度 · 动效  
   - 工作台 7 相位  
   - 组件样张（按钮 / 输入 / composer / badge）  
   - 页面骨架（工作台 / 设置 / 登录）  
   - 冻结规则与待收敛（可选）

4. **工作台相位**  
   是否需要完整 7 相位表？若只要部分，列出 phase 名。

5. **Canvas 文件名**  
   建议默认：`wuch-design-style.canvas.tsx` 或 `design-anchor.canvas.tsx`（若工作区已有同名，询问是否覆盖更新）。

## 选问（有则更好）

- 是否强调「仅浅色 / 减少动效」约束条？
- 是否要挂「打开 DESIGN-ANCHOR 文档」按钮（仅当工作区有 `docs/DESIGN-ANCHOR.md`）？
- 语言：中文（默认）/ 中英对照？

## 确认摘要模板

询问结束后，向用户发一段可勾选的摘要，例如：

```text
将产出 Canvas：<文件名>
产品语：<一句话或「基线总览」>
板块：色板 · 字体 · 动效 · 工作台相位 · 组件样张
相位：完整 7 个
主题：仅浅色（基线锁定）

回复「确认」后我写入画布；要改范围请直接说。
```

用户确认前：**不写文件、不声称已完成。**
