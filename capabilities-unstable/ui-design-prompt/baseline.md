# baseline.md

**全部风格的上位规则。** 任何风格、任何场景先满足本文件；与风格文件冲突时以本文件为准，风格文件明确声明例外者除外。

```text
一 · 圆角        分四档，按元素职责取
二 · 容器与背景   什么时候用 Card，什么时候只加背景
三 · 颜色体系     突出色 / 辅助色 / 语义色 / 中性阶
四 · 渐变        只给大面积背景与数据可视化
五 · 字体        三档字重 + 层级三要素 + 行高字距
六 · 图标        线性或实心，线宽与尺寸统一
```

---

## 一 · 圆角

四档。按元素职责取，不按喜好取。

| 档 | 值 | 用在 |
| --- | --- | --- |
| **方角** | `0–4` | 内容块、图文卡、数据表、编辑器 |
| **中性** | `8–12` | 输入框、标签、小按钮、缩略图 |
| **圆润** | `14–20` | 卡片、面板、弹层 |
| **全圆** | `999` | 按钮、chip、头像、开关 |

- 同页圆角档位 ≤ 3 种
- 嵌套：内层圆角 = 外层圆角 − 内边距，不小于 `4`
- 按钮与输入框圆角差 ≤ `2`
- 圆角与阴影同档：方角配硬阴影，大圆角配柔阴影
- 风格文件的 `R` 基数覆盖本表数值，档位关系不变

---

## 二 · 容器与背景

逐层问，问到底：

```text
需要分组吗
├─ 否 → 不加容器，靠间距分组
└─ 是 → 需要强调 / 可点击吗
        ├─ 是 → Card：面 + 圆角 + 阴影
        └─ 否 → 只加背景：面2，无阴影无圆角
```

**Card 的成立条件**：必须是「可点 / 可拖 / 有独立状态」的实体。纯展示的分组用背景或 `1px` 分割线。

- Card 必须有光影层次：双层弥散阴影 + `1px` 微边框，禁止平涂色块
- 一屏 Card ≤ 5 张；超过改用列表 + 分割线
- 背景层级 ≤ 3 层：页面底 → 区块面 → 卡面。需要第 4 层时用分割线，不再降背景
- 禁止 Card 套 Card 套 Card
- 全宽区块加背景的条件：需要切换语境（如深色 CTA 段），或承载满幅媒体
- 空状态 / 加载态不加 Card，用居中图形 + 一行说明

## 三 · 颜色体系

四个角色，缺一不可。占比是硬上限。

| 角色 | 变量 | 占比 | 用在哪 |
| --- | --- | --- | --- |
| **突出色** | `--brand` | ≤ `10%` | 主按钮、选中态、唯一关键数字 |
| **辅助色** | `--brand-2` | ≤ `5%` | 次级强调、图表第二序列 |
| **语义色** | `--success` `--danger` `--warning` | ≤ `3%` | 只表状态，不做装饰 |
| **中性阶** | `--bg` `--surface` `--ink` … | ≥ `80%` | 承载一切，层级靠它 |

- **突出色只有一个。** 第二个想强调的东西用字重 / 字号解决，不加第二个颜色
- 辅助色必须与突出色**同明度档**，否则互相打架
- 语义色不得当突出色用 —— 红色按钮只出现在危险操作
- 主按钮必须有质感（实心 / 发光 / 立体），形态见风格文件的「质感」段
- 页面底色饱和度 ≤ `8%`；正文对比度 ≥ `4.5:1`
- **禁止「浑浊」配色**：低饱和 + 中低明度 + 无对比。不是禁色相，是禁没对比
- 每款风格的 `--brand` 已定，**不得临场换色相**
- 浅色底不用纯白、深色底不用纯黑

## 四 · 渐变

**只给大面积背景与数据可视化，不给小控件。**

| 用在哪 | 允许 | 禁止 |
| --- | --- | --- |
| 背景 | Hero 光斑、全屏底 | — |
| 数据 | 数据柱、环形进度、热力 | — |
| 材质 | 铬面 / 金属（限 Chrome） | — |
| 控件 | — | 渐变按钮（除 Dark Tech）、渐变边框 |
| 文字 | — | 渐变文字 |
| 图标 | — | 渐变 icon |

- 方向统一 `135°`
- 两个 stop 之间色相差 ≤ `60°`
- 渐变上的文字必须过对比度检查，不足时加暗色遮罩
- 单页渐变面积 ≤ `40%`

## 五 · 字体

- **三档字重**：`400` 正文 / `500` 强调 / `600` 标题。超过三档 = 层级失控
- **层级三要素**：字号 + 字重 + 颜色，三者同时用，不只加粗
- 字号取风格文件的「字号用法」表，不跨级跳用
- 行高：正文 `1.6–1.85`，标题 `0.94–1.25`，随风格取
- 字距：大标题收紧 `-0.02 ~ -0.04em`；小标签放开 `+0.08 ~ +0.18em`
- 正文最大宽度 `60–75` 字符；超过必须限宽或分栏
- 中英混排加 `1/4` 空格；中文正文不居中
- 禁止 Lorem ipsum 与「标题1 / 内容内容」占位，用合理中文示例内容

---

## 六 · 图标

- **只用线性，或只用实心。** 同页不混
- 线宽同页统一，取风格文件指定值：`1.5` 细腻 / `1.75` 默认 / `2` / `2.5` 粗犷
- 尺寸只取 `16 / 20 / 24 / 28`，不取中间值
- 必须内联 SVG。**禁止**字符图标（`<` `>` `×` `+` `→` `⋯` `✓`）、emoji、CSS 圆点充当图标

  ```html
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round">
  ```
- 图标与相邻文字基线对齐；间距 = 图标宽度的 `1/4`
- 悬浮在图片或深色上：毛玻璃底 `rgba(0,0,0,.4)` + `blur(10px)` + `1px rgba(255,255,255,.18)`，尺寸 ≥ `28`
- 语义唯一：同一图标在同一产品里只表达一个意思
- 图标库同页只用一套（Lucide / Tabler 择一）
