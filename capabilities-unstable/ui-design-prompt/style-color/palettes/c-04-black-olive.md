# C-04 · 黑橄榄

`#000000` `#969B74` `#4E693E` `#1C301A` `#21134C` `#411C02` `#03111C`

纯黑主导 + 橄榄绿系 + 深紫点缀。

## 色值

| 色值 | 实测占比 | 建议角色 |
| --- | --- | --- |
| `#000000` | 63% | 墨 / 深面 |
| `#969B74` | 17% | 底 / 面 |
| `#4E693E` | 9% | 中性阶 |
| `#1C301A` | 5% | 中性阶 |
| `#21134C` | 4% | **突出色** |
| `#411C02` | 2% | 中性阶 |
| `#03111C` | 1% | 中性阶 |

## 来源

- 参考 `Color Palette Inspiration`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#21134C`（小面积点缀色）
- 适合 音乐、潮流、暗色品牌

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
