## 来源

- 参考 `Color Palette 44 Hex Codes Names ALIMAYDIDTHAT`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#D6E87A`（最大面积色，色度高，即主色）
- 适合 创意、儿童、插画、活动

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
