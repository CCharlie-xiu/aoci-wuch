## 来源

- 参考 `Color Palette Library 17 Hex Codes Names ALIMAYDIDTHAT`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#EFEB56`（小面积点缀色）
- 适合 潮流、音乐、活动海报

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
