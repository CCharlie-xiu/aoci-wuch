# C-01 · 深青霓虹

`#0F2B32` `#FCFEFE` `#02EEEF` `#20585D` `#6AF5F5` `#A4ADB0` `#088B8E`

深色底 + 霓虹青，对比极强。

## 色值

| 色值 | 实测占比 | 建议角色 |
| --- | --- | --- |
| `#0F2B32` | 33% | 墨 / 深面 |
| `#FCFEFE` | 27% | 底 / 面 |
| `#02EEEF` | 17% | **突出色** |
| `#20585D` | 8% | 中性阶 |
| `#6AF5F5` | 6% | 中性阶 |
| `#A4ADB0` | 5% | 中性阶 |
| `#088B8E` | 4% | 中性阶 |

## 来源

- 参考 `Switchlab Color Palette`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#02EEEF`（小面积点缀色）
- 适合 深色仪表盘、开发者工具、金融科技

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
