# C-12 · 海军蓝紫

`#E2E3F3` `#121F52` `#FFFFFF` `#5B65DC` `#F9F9FD` `#EDEEFC` `#777B8C`

淡蓝紫面 + 深海军蓝 + 蓝紫突出。

## 色值

| 色值 | 实测占比 | 建议角色 |
| --- | --- | --- |
| `#E2E3F3` | 31% | 中性阶 |
| `#121F52` | 16% | 墨 / 深面 |
| `#FFFFFF` | 14% | 底 / 面 |
| `#5B65DC` | 14% | **突出色** |
| `#F9F9FD` | 13% | 中性阶 |
| `#EDEEFC` | 12% | 中性阶 |
| `#777B8C` | 0% | 中性阶 |

## 来源

- 参考 `Medical website color palette`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#5B65DC`（小面积点缀色）
- 适合 医疗、SaaS、B 端后台

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
