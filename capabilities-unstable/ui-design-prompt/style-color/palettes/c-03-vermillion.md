# C-03 · 朱红撞白

`#F03413` `#EEF5F8` `#1A1C1B` `#550000` `#980100` `#F97907` `#6A7475`

朱红占近半，冷白托底。

## 色值

| 色值 | 实测占比 | 建议角色 |
| --- | --- | --- |
| `#F03413` | 47% | **突出色** |
| `#EEF5F8` | 21% | 底 / 面 |
| `#1A1C1B` | 20% | 墨 / 深面 |
| `#550000` | 4% | 中性阶 |
| `#980100` | 4% | 中性阶 |
| `#F97907` | 3% | 中性阶 |
| `#6A7475` | 1% | 中性阶 |

## 来源

- 参考 `A Cohesive Color Scheme`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#F03413`（最大面积色，色度高，即主色）
- 适合 活动页、创意机构、餐饮

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
