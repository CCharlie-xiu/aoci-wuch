| 色值 | 实测占比 | 建议角色 |

## 来源

- 参考 `Green Blue Color Palette for Logo Design`
- 实测 k-means `n=7`（原图 110×110 网格采样）
- 突出色 `#04ACF9`（小面积点缀色）
- 适合 医疗、环保、企业官网

## 用法

按 `style-color.md` 一 · 颜色四角色重新分配：突出色 ≤ `10%`、辅助色 ≤ `5%`、语义色 ≤ `3%`、中性阶 ≥ `80%`。
