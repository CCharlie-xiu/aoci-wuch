# style-color

**颜色规范与色阶库。** 决定「用什么颜色、占多少、怎么搭」。

```text
一 · 颜色四角色   突出色 / 辅助色 / 语义色 / 中性阶
二 · 渐变边界     只给大面积背景与数据可视化
三 · 色阶库       56 组标准色阶，色阶即规范
```

受 `baseline.md` 总纲约束；`styles/*.md` 只覆盖它明确声明的项。

---

## 一 · 颜色四角色

| 角色 | 变量 | 占比 | 用在哪 |
| --- | --- | --- | --- |
| **突出色** | `--brand` | ≤ `10%` | 主按钮、选中态、唯一关键数字 |
| **辅助色** | `--brand-2` | ≤ `5%` | 次级强调、图表第二序列 |
| **语义色** | `--success` `--danger` `--warning` | ≤ `3%` | 只表状态，不做装饰 |
| **中性阶** | `--bg` `--surface` `--ink` … | ≥ `80%` | 承载一切，层级靠它 |

- **突出色只有一个。** 第二个想强调的东西用字重 / 字号解决，不加第二个颜色
- 辅助色与突出色**同明度档**（取同色阶的 `300` 或 `700`），否则互相打架
- 语义色不得当突出色用 —— 红色按钮只出现在危险操作
- 主按钮必须有质感（实心 / 发光 / 立体），形态见 `style-looklike`
- 页面底色饱和度 ≤ `8%`；正文对比度 ≥ `4.5:1`
- **禁止「浑浊」配色**：低饱和 + 中低明度 + 无对比。不是禁色相，是禁没对比
- 浅色底不用纯白、深色底不用纯黑

## 二 · 渐变边界

**只给大面积背景与数据可视化，不给小控件。**

| 用在哪 | 允许 | 禁止 |
| --- | --- | --- |
| 背景 | Hero 光斑、全屏底 | — |
| 数据 | 数据柱、环形进度、热力 | — |
| 材质 | 铬面 / 金属（限 Chrome） | — |
| 控件 | — | 渐变按钮（除 Dark Tech）、渐变边框 |
| 文字 | — | 渐变文字 |
| 图标 | — | 渐变 icon |

- 方向统一 `135°`
- 两个 stop 之间色相差 ≤ `60°`
- 渐变上的文字必须过对比度检查，不足时加暗色遮罩
- 单页渐变面积 ≤ `40%`

## 三 · 色阶库

**色阶即规范。** 56 组标准色阶，全部从 Dribbble 配色类作品实测后展开：先 k-means 取该作品的突出色，再以其色相为轴按标准明度梯生成 `50 → 950` 共 11 级。

**突出色、面、描边、墨都从同一组取，不再单独定色。**

展示页 → `palettes.html`（浏览器打开，按色相筛选，点色块复制 hex）

### 色阶 → 角色映射

| 色阶 | 角色 | 用在哪 |
| --- | --- | --- |
| `50` | 底 | 页面底（浅色主题） |
| `100–200` | 面 / 浅强调 | 卡面、选中背景、标签底 |
| `300–400` | 描边 / 次要 | 边框、禁用态、图表辅助 |
| **`500–600`** | **突出色** `--brand` | 主按钮、选中态、关键数字 |
| `700` | 强调 hover | 按下态、深色文字 |
| `800–900` | 深面 | 深色区块、深色主题底 |
| `950` | 墨 | 深色主题文字 |

### 用法

1. 按场景从 `palettes.html` 选一组
2. 按上表把 11 级映射到 `:root` 变量
3. 中性阶**不单独找** —— 用同组色阶的低饱和档，或任取一组把饱和度压到 `5%` 以内
4. 语义色仍用固定三色，不从色阶取

### 色相覆盖

11 个色相族，共 56 组：

```text

洋红 4 · 黄绿 2 · 玫红 2 · 青绿 2 · 绿 1
```

## 与风格的关系

色阶与 `styles/*.md` 是两条路：

- **走风格**：需要成套视觉语言（字体 + 圆角 + 阴影 + 质感），选 `styles/`
- **走色阶**：已有形态语言，只缺配色，从色阶库取一组替换颜色组

两者可叠加：选一款风格为基底，用色阶替换它的颜色组 —— 但必须过 `tokens.md` 三·补的一致性检查。
