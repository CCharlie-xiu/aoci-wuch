# style-color

**颜色规范与色卡库。** 决定「用什么颜色、占多少、怎么搭」。

```text
一 · 颜色四角色   突出色 / 辅助色 / 语义色 / 中性阶
二 · 渐变边界     只给大面积背景与数据可视化
三 · 色卡库       从真实作品实测的 13 组配色，按场景索引
```

受 `baseline.md` 总纲约束；`styles/*.md` 只覆盖它明确声明的项。

---

## 一 · 颜色四角色

四个角色，缺一不可。占比是硬上限。

| 角色 | 变量 | 占比 | 用在哪 |
| --- | --- | --- | --- |
| **突出色** | `--brand` | ≤ `10%` | 主按钮、选中态、唯一关键数字 |
| **辅助色** | `--brand-2` | ≤ `5%` | 次级强调、图表第二序列 |
| **语义色** | `--success` `--danger` `--warning` | ≤ `3%` | 只表状态，不做装饰 |
| **中性阶** | `--bg` `--surface` `--ink` … | ≥ `80%` | 承载一切，层级靠它 |

- **突出色只有一个。** 第二个想强调的东西用字重 / 字号解决，不加第二个颜色
- 辅助色必须与突出色**同明度档**，否则互相打架
- 语义色不得当突出色用 —— 红色按钮只出现在危险操作
- 主按钮必须有质感（实心 / 发光 / 立体），形态见 `style-looklike`
- 页面底色饱和度 ≤ `8%`；正文对比度 ≥ `4.5:1`
- **禁止「浑浊」配色**：低饱和 + 中低明度 + 无对比。不是禁色相，是禁没对比
- 每款风格的 `--brand` 已定，**不得临场换色相**
- 浅色底不用纯白、深色底不用纯黑

## 二 · 渐变边界

**只给大面积背景与数据可视化，不给小控件。**

| 用在哪 | 允许 | 禁止 |
| --- | --- | --- |
| 背景 | Hero 光斑、全屏底 | — |
| 数据 | 数据柱、环形进度、热力 | — |
| 材质 | 铬面 / 金属（限 Chrome） | — |
| 控件 | — | 渐变按钮（除 Dark Tech）、渐变边框 |
| 文字 | — | 渐变文字 |
| 图标 | — | 渐变 icon |

- 方向统一 `135°`
- 两个 stop 之间色相差 ≤ `60°`
- 渐变上的文字必须过对比度检查，不足时加暗色遮罩
- 单页渐变面积 ≤ `40%`

## 与风格的关系

色卡与 `styles/*.md` 是两条路：

- **走风格**：需要成套视觉语言（字体 + 圆角 + 阴影 + 质感），选 `styles/`
- **走色卡**：已有形态语言，只缺配色，从本节选一组替换颜色组

两者可叠加：选一款风格为基底，用色卡替换它的颜色组 —— 但必须过 `tokens.md` 三·补的一致性检查。
