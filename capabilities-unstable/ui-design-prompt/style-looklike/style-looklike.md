# style-looklike

**组件形态规范。** 决定「东西长什么样」—— 圆角、容器、图标、组件清单。

```text
一 · 圆角        四档，按元素职责取
二 · 容器与背景   什么时候用 Card，什么时候只加背景
三 · 图标        线性或实心，线宽与尺寸统一
四 · 组件清单     本能力覆盖的组件与各自形态要求
```

受 `baseline.md` 总纲约束；`styles/*.md` 只覆盖它明确声明的项。

---

## 一 · 圆角

四档。**按元素职责取，不按喜好取。**

| 档 | 值 | 用在 |
| --- | --- | --- |
| **方角** | `0–4` | 内容块、图文卡、数据表、编辑器 |
| **中性** | `8–12` | 输入框、标签、小按钮、缩略图 |
| **圆润** | `14–20` | 卡片、面板、弹层 |
| **全圆** | `999` | 按钮、chip、头像、开关 |

- 同页圆角档位 ≤ 3 种
- 嵌套：内层圆角 = 外层圆角 − 内边距，不小于 `4`
- 按钮与输入框圆角差 ≤ `2`
- **圆角与阴影同档**：方角配硬阴影，大圆角配柔阴影
- 风格文件的 `R` 基数覆盖本表数值，档位关系不变

## 二 · 容器与背景

逐层问，问到底：

```text
需要分组吗
├─ 否 → 不加容器，靠间距分组
└─ 是 → 需要强调 / 可点击吗
        ├─ 是 → Card：面 + 圆角 + 阴影
        └─ 否 → 只加背景：面2，无阴影无圆角
```

**Card 的成立条件**：必须是「可点 / 可拖 / 有独立状态」的实体。纯展示的分组用背景或 `1px` 分割线。

- Card 必须有光影层次：双层弥散阴影 + `1px` 微边框，禁止平涂色块
- 一屏 Card ≤ 5 张；超过改用列表 + 分割线
- 背景层级 ≤ 3 层：页面底 → 区块面 → 卡面。需要第 4 层时用分割线，不再降背景
- 禁止 Card 套 Card 套 Card
- 全宽区块加背景的条件：需要切换语境（如深色 CTA 段），或承载满幅媒体
- 空状态 / 加载态不加 Card，用居中图形 + 一行说明

## 三 · 图标

- **只用线性，或只用实心。** 同页不混
- 线宽同页统一，取风格文件指定值：`1.5` 细腻 / `1.75` 默认 / `2` / `2.5` 粗犷
- 尺寸只取 `16 / 20 / 24 / 28`，不取中间值
- 必须内联 SVG。**禁止**字符图标（`<` `>` `×` `+` `→` `⋯` `✓`）、emoji、CSS 圆点充当图标

  ```html
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round">
  ```

- 图标与相邻文字基线对齐；间距 = 图标宽度的 `1/4`
- 悬浮在图片或深色上：毛玻璃底 `rgba(0,0,0,.4)` + `blur(10px)` + `1px rgba(255,255,255,.18)`，尺寸 ≥ `28`
- 语义唯一：同一图标在同一产品里只表达一个意思
- 图标库同页只用一套（Lucide / Tabler 择一）

## 四 · 组件清单

每个组件的形态要求。风格文件可覆盖尺寸与颜色，不可覆盖结构。

| 组件 | 圆角档 | 尺寸 | 必须有的状态 |
| --- | --- | --- | --- |
| **主按钮** | 全圆 / 中性 | 高 `40–52`，横向内边距 `18–24` | 默认 / hover / 按下 / 聚焦 / 禁用 / 加载 |
| **次按钮** | 全圆 / 中性 | 同主按钮 | 同上；靠描边或浅底区分 |
| **幽灵按钮** | 全圆 | 同主按钮 | hover 才有底色 |
| **图标按钮** | 全圆 | `32 / 38 / 44` 方形 | hover / 按下 / 聚焦 |
| **输入框** | 中性 | 高 `40–44` | 默认 / 聚焦 / 已填 / 错误 / 禁用 |
| **搜索框** | 全圆 | 高 `44–46` | 默认 / 聚焦 / 有值（带清除） |
| **卡片** | 圆润 | 内边距 `16–24` | 默认 / hover 抬升 / 选中 |
| **标签 chip** | 全圆 | 高 `28–36` | 默认 / 选中（反色）/ 可关闭 |
| **头像** | 全圆 | `24 / 32 / 40 / 48` | 默认 / 带在线点 / 带边框 |
| **列表项** | 方角 / 中性 | 高 `56–72` | 默认 / hover / 选中 / 禁用 |
| **分段控件** | 全圆 | 高 `36–44`，容器内边距 `4` | 选中项反色实心 |
| **底部导航** | 全圆（悬浮）/ 方角（贴底） | 高 `56–72` | 当前项必须有选中态 |
| **顶部导航** | 方角 | 高 `56–64` | 滚动时阴影递进 |
| **表格** | 方角 | 行高 `44–52` | 表头固定 / 行 hover / 排序态 |
| **弹层 / 抽屉** | 圆润 | 最大宽 `400–480` | 入场动效 / 遮罩 / 关闭钮 |
| **空状态** | — | 图形 `80–120` | 必须有图形，不能只有一行字 |
| **骨架屏** | 圆润 | 与真实内容同尺寸 | 微光扫过，`1.4s` 循环 |
| **进度 / 环形** | 全圆 | 线宽 `6–14` | 确定态带数值 / 不确定态循环 |

### 按钮三级分明

- **主**：实心 + 质感（光泽 / 发光 / 立体），一屏一个
- **次**：描边或浅底，可有多个
- **幽灵**：无底色，用于低优先级动作

### 卡片统一性

同一列表里的卡片必须**统一圆角 + 统一阴影 + 统一内边距**。任何一个不同都会显得脏。
