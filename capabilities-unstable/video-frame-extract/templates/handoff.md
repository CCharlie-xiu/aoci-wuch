# handoff

交付与回问话术。能力只生成产物，向用户展示由调用方完成。

## 交付（≤12 张）

```text
已从 <视频名> 抽取 N 张图片（<模式说明>）：
[图片] [图片] [图片]
产物目录：<out>/frames/
```

## 交付（>12 张：先总结，再给压缩包）

```text
已从 <视频名> 抽取 N 张（<模式>，间隔 X 秒，覆盖 00:00 – 00:MM）。

首尾预览：
[首帧] [中帧] [尾帧]

全部图片：<压缩包路径>（N 张 + manifest.json）
目录：<out>/frames/

需要我按时间点挑几张展开，或拼成联系表吗？
```

总结要素固定四项：来源、数量、间隔、时间跨度。不要逐张罗列。

## 超限（LIMIT_EXCEEDED）

```text
按「每秒一张」需要约 2400 张，超过当前默认上限 600。
要保持每秒抽一张（放宽上限），还是改成均匀抽 600 张？
```

## 越界（视觉语义筛选）

```text
「最有代表性的画面」需要看懂画面内容，抽帧能力只能做时间和场景采样。
我可以先高密度抽帧（例如每 2 秒一张），再逐张看图筛选。要这样走吗？
```

## 缺参数

```text
需要确认：抽多少张，或每隔几秒抽一张？
```
